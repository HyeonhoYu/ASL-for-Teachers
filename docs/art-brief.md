# Frog Baby Art Brief

Use this when making new or higher-quality Frog Baby pictures in the same image tool you used for the original character sheet.

## File specs

- One pose per image, full body, centered, nothing cropped (star to feet).
- At least 1600 x 1600 pixels.
- Transparent background (PNG). If the tool cannot do transparency, use a plain solid light background with no shadow on the floor.
- No text in the image.
- Same camera angle and lighting in every image.

## Character description (paste this at the start of every prompt)

Cute 3D clay-style toy figure of a young child named Frog Baby, big round head, brown bowl-cut hair with a small top bun, a glowing gold star on top of the bun, rosy cheeks, simple dot eyes, white short-sleeved T-shirt, dark red overalls with a front pocket and two gold buttons, dark red shoes, standing on a green lily pad base, soft studio lighting, smooth matte texture, high detail, centered, full body.

## Avoid

Do not ask the tool to draw Frog Baby making specific ASL handshapes. Image tools often get fingers wrong, and a wrong handshape teaches the wrong sign. The site's hand drawings in `images/handshapes`, `images/letters`, and `images/numbers` handle that part.

## Replacing a picture

Save the new picture with the same file name in `images/` (convert to `.webp` if you can; a `.png` also works if you change the file ending where it is used). The site picks it up automatically.
